# 🔥 UP09 — Firebase

**Firebase** es la plataforma de Google que ofrece servicios en la nube listos para usar en aplicaciones móviles. En esta unidad integrarás Firebase en una aplicación Android y usarás **Analytics**, **Authentication**, **Cloud Messaging**, **Crashlytics**, **Remote Config** y las bases de datos **Realtime Database** y **Cloud Firestore**.
