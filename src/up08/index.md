# 🌐 UP08 — Consumo de APIs

Muchas aplicaciones obtienen sus datos de **servicios web**. En esta unidad conocerás la arquitectura orientada a servicios y las **API REST**, harás peticiones HTTP a mano con `HttpURLConnection` y construirás una aplicación completa con **Retrofit** siguiendo la arquitectura MVVM.

## Contenidos

| Apartado | Qué vas a aprender |
|:---|:---|
| [1. Servicios web y API REST](./contenidos/01-servicios-web-api-rest) | SOA, API REST, métodos HTTP y endpoints, imágenes con Coil, permiso `INTERNET`, `HttpURLConnection` y librerías HTTP |
| [2. Retrofit](./contenidos/02-retrofit) | Caso de estudio con la API de Rick y Morty: dependencias, *data classes* desde JSON, servicio, factoría, ViewModel e interfaz |
