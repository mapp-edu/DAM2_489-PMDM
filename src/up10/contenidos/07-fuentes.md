# 7. Fuentes de consulta

Fuentes utilizadas para elaborar esta unidad y recomendadas para ampliar. Las páginas web se consultaron en **octubre de 2026**; como los motores evolucionan rápido, comprueba siempre la versión de la documentación (en el curso, **Unity 6.3 LTS**).

## Documentación oficial de Unity

| Recurso | Contenido | Apartados |
|:---|:---|:---|
| [Unity Manual](https://docs.unity3d.com/Manual/index.html) | Manual de referencia del editor y de todos los sistemas del motor. | Todos |
| [Scripting API](https://docs.unity3d.com/ScriptReference/) | Referencia de clases C# (`MonoBehaviour`, `Rigidbody`, `AudioSource`…). | 3, 4, 5 |
| [Order of execution for event functions](https://docs.unity3d.com/Manual/execution-order.html) | Ciclo de vida de los scripts. | 3 |
| [Input System](https://docs.unity3d.com/Packages/com.unity.inputsystem@latest) | Acciones, dispositivos y controles en pantalla. | 3 |
| [Cinemachine](https://docs.unity3d.com/Packages/com.unity.cinemachine@latest) | Cámaras procedurales 2D y 3D. | 4, 5 |
| [ScriptableObject](https://docs.unity3d.com/Manual/class-ScriptableObject.html) | Contenedores de datos. | 3 |
| [PlayerSettings.Android.targetArchitectures](https://docs.unity3d.com/ScriptReference/PlayerSettings.Android-targetArchitectures.html) | Arquitecturas de destino en Android (Unity 6.3 LTS). | 6 |
| [Unity 6.3 LTS is now available](https://unity.com/blog/unity-6-3-lts-is-now-available) | Novedades y soporte de la versión LTS usada en el curso. | 2 |

## Guías técnicas gratuitas de Unity (e-books)

- Unity Technologies. [*2D game art, animation, and lighting for artists* (Unity 6.3 LTS edition)](https://unity.com/resources/2d-game-art-animation-lighting-unity-6-3-lts). Sprites, tilemaps, animación y luces 2D. Apartado 4.
- Unity Technologies. [*Optimize your game performance for mobile, XR, and the web in Unity* (Unity 6 edition)](https://unity.com/resources/mobile-xr-web-game-performance-optimization-unity-6). Profiling y optimización en móvil. Apartado 6.
- Unity Technologies. [Guías de optimización de Unity 6](https://unity.com/blog/unity-6-game-optimization-guides). Recopilación de guías por plataforma. Apartado 6.

## Cursos de Unity Learn

- [Unity Learn — Pathways](https://learn.unity.com/pathways): itinerarios gratuitos y guiados.
  - [Unity Essentials](https://learn.unity.com/pathway/unity-essentials): primeros pasos con el editor (apartado 2).
  - [Junior Programmer](https://learn.unity.com/pathway/junior-programmer): programación en C# para Unity (apartado 3).
  - [Creative Core](https://learn.unity.com/pathway/creative-core): materiales, iluminación, audio, animación y VFX (apartado 5).
- [2D Game Kit](https://learn.unity.com/course/unity-basics/unit/2d-game-kit/tutorial/get-started-with-the-2d-game-kit) y [Explore a Microgame](https://learn.unity.com/course/game-design-curricular-framework-resources/tutorial/explore-a-microgame): proyectos completos para analizar y modificar (Prácticas 1 y 2).

## Otros motores

## Lenguaje C# y Android

- Google. [Requisito de nivel de API objetivo de Google Play](https://developer.android.com/google/play/requirements/target-sdk). Apartado 6.

## Bibliografía

- **Gregory, J.** (2018). *Game Engine Architecture* (3.ª ed.). CRC Press. Referencia sobre la arquitectura y los componentes de un motor (apartado 1).
- **Nystrom, R.** (2014). *Game Programming Patterns*. Genever Benning. [Edición web gratuita](https://gameprogrammingpatterns.com/): bucle de juego, *update method*, componentes, *object pool*, máquina de estados (apartados 1, 3 y 6).
- **Schell, J.** (2019). *The Art of Game Design: A Book of Lenses* (3.ª ed.). CRC Press. Diseño de juegos y documento de diseño (apartado 6).
- **Hocking, J.** (2022). *Unity in Action* (3.ª ed.). Manning. Desarrollo práctico 2D y 3D con Unity y C#.
