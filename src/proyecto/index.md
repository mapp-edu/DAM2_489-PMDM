# 🚀 Proyecto de curso — *Explora*

Durante todo el curso desarrollarás **una única aplicación Android** que irá creciendo con cada unidad: ***Explora***, una app para descubrir lugares de tu entorno y superar **retos** en ellos (como una yincana), que en la última fase se completa con un **minijuego** en Unity. Cada evaluación termina con una **entrega parcial** que se evalúa con su propia rúbrica.

::: accent-box primary 📖 La idea en una frase
*Explora* muestra un catálogo de **lugares** (monumentos, rutas, comercios, rincones…) con **retos** asociados; el usuario los visita, demuestra que ha estado allí con su **ubicación, una foto o un audio**, gana **insignias** y, al completar una ruta, desbloquea un **minijuego**.
:::

::: tip-box Elige tu temática
La estructura es fija, pero la **temática es libre**: patrimonio de tu localidad, rutas de senderismo, un museo, restaurantes, instalaciones deportivas, un campus, un festival… Debes proponerla en el primer hito y debe permitir cumplir todos los requisitos.
:::

## Evaluación del proyecto

| Aspecto | Criterio |
|:---|:---|
| **Peso** | Propuesta: el proyecto supone el **40 %** de la nota de cada evaluación; el 60 % restante corresponde a las actividades de las unidades. |
| **Hitos de seguimiento** | No puntúan, pero son **obligatorios**: sirven para revisar el avance y dar retroalimentación. |
| **Rúbricas** | Cada fase tiene su rúbrica. Cada elemento se valora de 0 a 4 y la nota de la fase es la **media** de sus elementos. |
| **Mínimo** | **Nivel 2 (5 puntos)** en la nota de cada fase para superarla. |
| **Defensa** | Cada entrega incluye una **defensa** (presencial o por videoconferencia) de 10 minutos. Sin defensa, la fase no se califica. |
| **Recuperación** | Una fase no superada se puede volver a entregar junto con la siguiente; en la Fase 3, en la convocatoria ordinaria final. |
| **Trabajo personal** | El proyecto es **individual**. El uso de IA generativa o la copia de código supondrá un **cero** en la fase. Las librerías y los assets de terceros deben citarse. |
