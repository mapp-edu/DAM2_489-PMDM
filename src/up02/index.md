# 🟣 UP02 — Fundamentos de Kotlin

**Kotlin** es el lenguaje oficial y preferente para el desarrollo Android. En esta unidad aprenderás su sintaxis y sus particularidades frente a Java —*null safety*, expresiones, colecciones, clases concisas, funciones de alcance y lambdas— trabajando con *scripts* en IntelliJ IDEA. Todo lo que veas aquí será la base de las aplicaciones con Jetpack Compose de las próximas unidades.

## Contenidos

| Apartado | Qué vas a aprender |
|:---|:---|
| [1. Sintaxis, tipos de datos y null safety](./contenidos/01-sintaxis-tipos) | IntelliJ IDEA, variables, tipos, cadenas, *arrays*, constantes, operadores, null safety, expresiones regulares y excepciones |
| [2. Control de flujo, colecciones y funciones](./contenidos/02-control-colecciones-funciones) | `if` y `when` como expresiones, rangos, bucles, `List`, `Set`, `Map` y funciones |
| [3. Programación orientada a objetos](./contenidos/03-poo) | Clases, constructores, `companion object`, `enum class`, `data class`, extensiones, `object`, herencia y clases abstractas |
| [4. Funciones de alcance y lambdas](./contenidos/04-funciones-alcance-lambdas) | `let`, `run`, `also`, `apply`, `with` y funciones de orden superior |
